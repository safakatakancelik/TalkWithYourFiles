Describe an image file in words, so that it can be searched and cited.

Input:
- `fileName`: the image file. The image itself is attached.

Output:
- `description`: a plain description of what the image shows: any text in it, word for word; what is pictured; and for a chart or table, its title, axes, labels and values.

Rules: describe only what is visible. Do not interpret or judge it.
