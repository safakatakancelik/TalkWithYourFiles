# Talk With Your Files

Have a conversation with your files. An agent-orchestrated RAG app that lets you ask about, explore and work with your documents in plain language.

Revision 2 is a full rewrite that is in progress. So far it has the UI only, running on a mock backend with a built-in demo.

```
cd frontend
npm install
npm run dev
```

Open the address it prints and press "Run demo". Run the scenario test with `npm test`.
