# Citations

A citation can only be created from a quote that is found, character for character, in the file's text.

| File | What it is |
|---|---|
| `locate.py` | `create_citation`: finds the quote, builds the passage, records the citation; `try_quote` checks without creating |
| `check.py` | The mechanical check: the quote and passage are exactly where the citation says, in the version it names |
| `normalize.py` | The canonical form of text that both stored text and quotes are compared in |
